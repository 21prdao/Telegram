# 代币价格定期刷新与显示优化

本次更新内容：

1. 客户端钱包首页、代币列表页、代币详情页都会在页面可见时每 60 秒自动刷新一次行情/估值；页面不可见时停止计时，避免后台无意义请求。
2. 未知价格不再显示 `$--`，统一显示 `--`；如果持仓数量为 0，持仓估值仍显示 `$0.00`。
3. 小数点后连续 0 太多的价格，使用类似 TokenPocket 的紧凑显示，例如：
   - `0.00008009` 显示为 `$0.0₄8009`
   - `0.00000123` 显示为 `$0.0₅123`
   - `0.0000001234` 显示为 `$0.0₆1234`
4. 金额估值固定两位小数，例如 `$12.30`、`$1,234.56`、`$<0.01`。
5. 服务端新安装默认外部行情缓存时间改为 60 秒；如果旧库中的该值仍是上一版自动初始化的 `300`，服务端启动时会自动迁移为 `60`。如果你后来在后台手动改过这个值，服务端会保留你的设置。

客户端自动刷新周期统一在：

```java
wallet/config/WalletConfig.java
TOKEN_PRICE_REFRESH_INTERVAL_MS = 60_000L
```

`wallet/ui/WalletUiRefreshPolicy.java` 会读取这个值，钱包首页、代币列表页、代币详情页统一使用同一刷新周期。
